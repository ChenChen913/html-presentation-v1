01 · 布局简史

布局这二十年，走了多远

2004-2012
float 时代
用文字环绕实现分栏，清除浮动成为必修 hack。
2012-2017
Flexbox 兴起
一维排列终于原生，垂直居中不再是玄学。
2017-2023
Grid 落地
行与列同时规划，页面骨架第一次有了「图纸」。
2023-今
容器查询
组件按自己容器自适应，响应式进入组件时代。
工具的演进方向始终一致：让「画界面」越来越接近「描述意图」。
02 · FLEXBOX 回顾

一维布局，四个关键习惯

  • 间距交给 gap，告别 margin 的负值 hack 与首尾特判。
  • 卡片自适应用 flex-basis 定基准、flex-grow 分剩余。
  • 基线对齐用 align-items: baseline，图文混排不再手调。
  • 水平居中用 margin-inline: auto，语义清晰无副作用。
/* 一行解决：等分 · 可换行 · 有间距 */
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.cards > .card { flex: 1 1 240px; }
03 · GRID 实战

命好名，页面自己会长出来

.page {
  display: grid;
  grid-template-areas:
    "head head"
    "side main"
    "foot foot";
  grid-template-columns:
    220px 1fr;
  grid-template-rows:
    auto 1fr auto;
}
.page > header { grid-area: head; }
.page > aside  { grid-area: side; }

命名区域让布局「所见即所得」：CSS 里的引号图形，就是页面的最终结构。

  • 调整结构只改一处，不再追着媒体查询写覆盖。
  • 组件用 grid-area 各就各位，职责一目了然。
  • 响应式换骨架：小屏重画一次 areas 即可。
04 · 响应式新范式

容器查询：组件自己会响应

  • 观察单位从「屏幕」变成「容器」，组件放到哪都对。
  • 同一张卡片，侧栏里紧凑、主区里舒展，一套代码。
  • 媒体查询退居二线，只管页面级断点。
迁移口诀：先给容器报名（container-type），再让组件做题（@container）。
/* 1. 声明查询容器 */
.card-list {
  container-type: inline-size;
}
/* 2. 组件按容器宽度响应 */
@container (min-width: 480px) {
  .card {
    display: grid;
    grid-template-columns: 96px 1fr;
  }
}

四种方案，一张表看清

方案维度响应单位适用场景支持率

Flexbox一维容器主轴导航、按钮组、列表项99.8%

结论：骨架用 Grid，局部用 Flex，组件自适应交给容器查询——三者是搭档，不是对手。
总结

带回工位的五条实践

  • 页面骨架交给 Grid，一维排列交给 Flexbox，别互相硬凹。
  • float 只用于文字环绕，不再承担任何布局职责。
  • 新组件优先 @container，页面级断点再用 @media。
  • 布局代码控制在三层嵌套以内，超出就该重画区域。
  • 升级老页面：先 gap 化、再 grid 化，小步重构不冒进。
