# 风格模板库 TEMPLATES.md

本库共 **20 套**单文件 HTML 模板：**液态玻璃家族**（01-08 经典八套 + 09-12 新增成员）、**Keynote 发布会变体**（13-18）、**美术馆画册变体**（19）与**东方卷轴变体**（20）。除特别注明外，每套均为 **10 页完整示例**，页面内容是一场真实、连贯的演示，可直接作为排版与信息密度的参照。

**使用方式（模板优先）**：不要从零写 HTML。选定一套模板后，复制该文件作为底稿，保留其全部 CSS 与 `<script>` 引擎，逐页替换文字内容即可。这样能天然继承验证过的排版、动效与零依赖保证。

## 三、10 页标准结构（玻璃系 01-18 统一；19 为画册结构、20 为卷轴结构）

| 页 | 角色 | 说明 |
|----|------|------|
| 1 | 封面 | 主标题 + 副题 + 演讲者/日期 |
| 2 | 目录 | 4 个章节条目 |
| 3 | 背景与问题 | 3-5 条要点 + 强调框，交代「为什么要讲」 |
| 4 | 核心理念/方法 | 两列卡片或大字观点，全场唯一核心信息 |
| 5 | 关键数据 | 3 张数据卡（或图表页），数字必须真实可信 |
| 6 | 对比分析 | 表格或双列对比，制造认知冲突 |
| 7 | 实施路径 | 3 步时间线/步骤条，给出可执行路径 |
| 8 | 深入细节 | 本模板特色组件的展示位（代码/定义/引用/卡片） |
| 9 | 总结与展望 | 要点回顾 + 下一步，呼应封面主题 |
| 10 | 结尾 | 致谢 + 联系方式 + 一句收束金句 |

改写内容时保持此骨架：**换内容不换结构**，每页信息密度对照原页即可。

**画册变体（19）的 10 页骨架**：封面（VOL 期号 + 衬线大字）→ 目录（细线条目）→ 图文分栏页（章标题占左 2/3 + 正文两栏右下 + 玻璃画框）→ 金句大字页 → 图文分栏页 → 清单/表格页（编辑表格）→ 数字页（画册式大数字）→ 图文分栏/引文页 → 金句页 → 结尾/版权页（COLOPHON 风）。页型覆盖要求：封面/目录/图文分栏/金句大字/结尾五种。

**卷轴变体（20）的 10 页骨架**：中轴楹联封面（竖排大题 + 左右楹联 + 玻璃月 + 印章）→ 五条屏玻璃目录（五片竖排屏风错落）→ 章回图文页（章回汉字 + 竖排章名 + 横排两栏正文 + 茶盏）→ 整页竖排金句（玻璃月 + 落款）→ 章回屏风卡页（三片竖排卡）→ 鎏金横条数据页 → 细金线表格页 → 竖向卷轴时间线（汉字纪年）→ 章回信息页（竖排两列标题 + 信息栏 + 印章落款）→ 竖排收束结尾（玻璃月 + 印章）。竖排元素高度预算：列字数 × 字号 ×（1+字距）必须 ≤ 容器高。

## 四、统一引擎（全部模板内嵌，禁止改动其行为）

玻璃系模板（01-12）共享同一段幻灯片引擎（约 60 行，内联于文件底部）；13-20 在同一引擎上增加滚轮翻页（750ms 惯性节流）：

- 键盘：`←` `→` `↑` `↓` `空格` `PageUp` `PageDown` 翻页，`Home` `End` 首尾页，`F` 全屏
- 触摸：左右滑动 > 60px 翻页
- 滚轮（仅 13-20）：`deltaY` 超阈值翻页，750ms 节流防触控板惯性连翻
- 按钮：`data-action="prev" / "next"` 事件委托
- 进度：`#progressFill`（宽度百分比）+ `#pageCounter`（页码文本），两者可缺省（如 03 用进度圆点替代页码；19 页码由杂志式四角细节静态承担；20 为汉字纪年角标 + 底部计数器）
- 深链：URL `#5` 直达第 5 页；`hashchange` 监听支持浏览器前进/后退
- 过渡：由各模板 CSS 决定——玻璃家族统一 600-800ms 优雅慢入（02 为 0.6s 回弹变奏）；`prefers-reduced-motion` 全部降级
- 焦点守卫（07/08 附加）：焦点在 contenteditable/表单元素时忽略快捷键

**改内容时的三条铁律**：
1. 不删除引擎、不更换 `class="slide"` 结构、不引入外部资源。
2. 换主题色只改 `:root` 里的 CSS 变量（及暗色变量块），不逐处替换色值。
3. 每页改完对照原页信息量：原文 4 条要点就写 4 条以内，禁止超载。

## 五、CSS 变量速查（玻璃系示例）

```css
:root {
  --bg:            /* 页面底色（渐变或纯色） */
  --glass:         /* 舞台毛玻璃底 rgba */
  --glass-border:  /* 玻璃描边 */
  --card-bg:       /* 内部卡片底 */
  --ink:           /* 主文字 */
  --ink-soft:      /* 次文字 */
  --accent:        /* 唯一强调色 */
  --accent-soft:   /* 强调色 10-14% 透明版，用于 note 框底色 */
}
```

12 套玻璃系全部沿用同一套变量命名；02 的✦列表符、04 的学术眉标为各自受控签名，见 AVOID_LIST.md。13-18 变量同名但色值为各自发布会体系（如 `--accent` 焦糖橙/蜂蜜金/青瓷绿/星芒蓝/冰川蓝/极光青），并额外定义 `--accent-deep` 渐变收尾辅助色（13 另有 `--gold` 蜂蜜金双辅助色；18 另有 `--accent2` 雾紫双点缀，用于极光带/章节条/时间线）。19 画册体系：`--line/--line-strong` 双细线、`--red` 朱砂红（只做细线/页码/关键词）、`--frame-border` 玻璃画框描边。20 卷轴体系：`--gold/--gold-deep` 鎏金双辅助、`--seal` 印章朱、`--gold-line` 金细线、`--glass-border` 金描边玻璃。

双主题模板（07/08）在 `[data-theme="dark"]` 中覆盖同名变量，切换逻辑只改 `body` 的 `data-theme` 属性。
